# Сайт «Калькуляторы стройка»
https://winstonpub.github.io/stroikacalc/

> **Важно про пароль записи в Google-таблицу.** Раньше пароль `e2612s` был зашит в файле
> `scripts/settings-sheet-api.gs`, а репозиторий публичный, — то есть его знал каждый посетитель.
> Откройте Google-таблицу → **Extensions → Apps Script** и смените строку `TOKEN` на новый
> секретный пароль, а затем впишите этот же пароль в админке («Подключение к таблице» →
> «Пароль записи»). В самом репозитории оставлена только заглушка `ВАШ-НОВЫЙ-ПАРОЛЬ-ЗАПИСИ`.

## Доступ в «Администрирование»

Вход в панель `#/admin` защищён базой данных **Supabase**: нужны почта и пароль аккаунта,
а право на доступ подтверждается записью в таблице `admins`.

- Инструкция по подключению базы и выдаче доступа — в файле [SUPABASE.md](SUPABASE.md).
- SQL-скрипт создания таблицы администраторов — в файле [supabase/schema.sql](supabase/schema.sql).
- Данные для подключения (Project URL и anon-ключ) вписываются в
  `src/integrations/supabase/config.ts`.
